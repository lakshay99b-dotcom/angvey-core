# angvey-core

**ANGVEY Core Product**  
Daily-evolving AI solution targeting the most unique and highly pinching problems in the world.

## Day 23 (15 Nov 2026) — Judgment Drain Packets: Kill the Agent Approval Queue Tax

Attacked the residual judgment-drain tax: after setting locked rules/prefs and generating Grill-Before-Act packets, solopreneurs still lose hours to agents that drip micro-questions, re-open settled preferences, or force constant approval of low-risk defaults. Each interruption creates attention residue and depletes the finite daily judgment budget. Task lists and raw memory do not force agents into batching + auto-proceed mode.

**Problem attacked:** Judgment drain and decision-queue fatigue compound when agents are not forced to self-resolve against locked memory and surface only true open conflicts in one compact batch. Inspired by trending agent skills (Matt Pocock grill-me for alignment-before-act, ECC/verification patterns, persistent memory handoffs) and documented agent failure modes (constant escalation, micro-approvals). Few lightweight tools turn client locked preferences into a one-paste packet that forces auto-proceed on defaults + single batched question list only.

**What shipped:**
- Storage bumped to v23 (auto-loads v22–v8)
- New Judgment Drain Packets: one-click generates markdown listing locked rules + prefs + open next actions, with strict instructions for any agent to auto-proceed on matching items, batch only true conflicts with recommended defaults, and output only the summary + batch (or none)
- Buttons in Daily Brief and Skill Cards section (scoped by client filter)
- Subtitle and export version updated
- Still zero-dependency, instant Vercel deploy

## Day 22 (14 Nov 2026) — Grill-Before-Act Packets: Kill the Pre-Action Alignment Tax

Attacked the residual decision-queue tax: after logging rules, preferences, and generating skill/compliance packets, solopreneurs still spend cycles re-explaining locked client decisions every time an agent proposes an option or asks a clarifying question that re-opens already-settled preferences. Agents treat context as soft; locked memory is not forced into the reasoning loop before action.

**Problem attacked:** Attention residue and rework compound when agents are not forced to self-grill against non-negotiable rules/prefs before proposing work. Inspired by trending agent skills (Matt Pocock grill-me for alignment-before-act, ECC/verification patterns, persistent memory handoffs). Few lightweight tools turn client locked preferences into a one-paste packet that forces confirmation + single compliant next action only.

**What shipped:**
- Storage bumped to v22 (auto-loads v21–v8)
- New Grill-Before-Act Packets: one-click generates markdown listing locked rules + prefs for a client (or general), with strict instructions for any agent to confirm understanding, flag conflicts, and output only a single aligned next action (or STOP)
- Buttons in Daily Brief and Skill Cards section (scoped by client filter)
- Subtitle and export version updated
- Still zero-dependency, instant Vercel deploy
