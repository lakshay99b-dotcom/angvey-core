# angvey-core

**ANGVEY Core Product**  
Daily-evolving AI solution targeting the most unique and highly pinching problems in the world.

This is the single focused project that the daily automation works on. All other repos remain untouched.

## Mission
1. Continuously scan the internet and GitHub for newly uploaded / trending open-source AI libraries and code.
2. Identify under-served, high-pain problems that few (or no one) is solving well.
3. Build and improve a real working product that attacks that problem.
4. Every day: research → adapt best open-source patterns → improve the code → report + deploy.

## Daily Process (Automated)
- Research latest trending free open-source GitHub AI libraries/code
- Find the most unique + pinching problem
- Write / improve code in this repository only
- Update outdated or weak parts
- Produce a clear change report
- Send short email summary (30-40 words) + working Vercel link
